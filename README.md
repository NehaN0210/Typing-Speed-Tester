# Typing-Speed-Tester

## About

A simple Python project that tests typing speed and accuracy.

## Features

- Random typing sentence
- Calculates typing speed in WPM
- Calculates typing accuracy
- Measures time taken

## Technologies Used

- Python
- Time module
- Random module

## How to Run

```bash
python main.py
```
